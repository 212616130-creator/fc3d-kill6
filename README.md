## 🔥 核心卖点

1. **双引擎互为校验** — kill1 V8 条件决策树 + kill2 独立算术公式，两套逻辑独立运算，任一引擎误杀即不计数
2. **每日自动更新** — 开奖后 22:00 / 23:30 / 次日 01:00 三重 cron 自动抓数、回测、发布，无需人工干预
3. **无未来信息** — 回测严格按期号回溯，输入仅上期开奖号 `(b, s, g)`，不含任何未来数据，数字可审计
4. **纯函数零依赖** — Go 单二进制，无数据库无运行时依赖，本地/云端/Docker 任意部署
5. **透明可自建** — 数据源、引擎、回测逻辑全部开源，自带升级触发器（100 期 <70% 或单月下滑 ≥8pp 自动红条告警）

## 🚀 快速开始

```bash
go build -o fc3d-kill6 .
./fc3d-kill6              # 抓数 → 追加CSV → 回测 → 生成index.html → 升级检测
go test ./...             # 引擎基准一致性测试
```

Docker 一条命令自托管：

```bash
docker build -t fc3d-kill6 .
docker run --rm -v $(pwd):/data fc3d-kill6 \
  -csv /data/fc3d-history.csv -html /data/index.html -kill6 /data/kill6_history.json
```
